# 个人 Skill 仓库桌面端 GUI 设计稿

## 1. 设计目标

该界面用于管理个人收藏和维护的 Skills。用户可以通过 AI 导入快速创建 Skill 条目，也可以手动新增、编辑、删除条目，并快速浏览 Skill、按标签筛选、查看安装方法、复制安装命令。

界面应偏工具型，保持清晰、紧凑、可扫描，不做营销式首页。

## 2. 信息架构

应用采用三栏布局：

- 左侧导航栏：全局入口、标签筛选、数据管理入口。
- 中间列表栏：搜索、排序、Skill 列表。
- 右侧工作区：默认展示 AI 导入面板，也可切换到 Skill 详情、安装方法和编辑表单。

默认进入应用后展示全部 Skills，并在右侧打开 AI 导入面板。

## 3. 主界面布局

### 左侧导航栏

宽度约 220px。

包含：

- 应用名称：个人 Skill 仓库
- 快捷入口：
  - 全部 Skills
  - 最近更新
  - 未分类
- 标签分组：
  - 文档处理
  - 飞书
  - 前端
  - 自动化
  - 数据分析
- 数据入口：
  - 导入
  - 导出
  - 设置

左侧导航用于快速缩小列表范围。

### 中间列表栏

宽度约 360px。

顶部包含：

- 搜索框：支持按名称、简介、标签、适用场景搜索。
- AI 导入按钮：默认主入口，用户粘贴 Skill 下载网址或资料网址后生成条目草稿。
- 手动新建按钮：创建空白 Skill 条目。
- 排序菜单：
  - 最近更新
  - 名称 A-Z
  - 创建时间

列表卡片展示：

- Skill 名称
- 一句话简介
- 标签
- 来源链接状态
- 更新时间

选中卡片后，右侧显示对应详情。

### 右侧工作区

占据剩余宽度。

默认面板为 AI 导入。AI 导入面板包含：

- Skill 下载网址或资料网址，必填
- 简短自然语言补充要求，可选
- 允许联网检索开关，默认开启
- 资料来源预览
- 生成草稿按钮
- 保存草稿为 Skill 条目按钮

AI 导入作为默认主流程：用户提供 Skill 下载网址或资料网址，AI 在用户授权联网后自行访问网页、查找相关资料、归纳安装方法，并生成可编辑 Skill 草稿。草稿不会自动入库，必须由用户确认保存。

详情页包含：

- Skill 名称
- 简短介绍
- 标签
- 适用场景
- 兼容平台
- 来源链接
- 安装步骤
- 安装命令代码块
- 备注
- 条目信息，包括平台、来源、创建时间、更新时间。该区域放在备注下方，不放在右侧独立栏。

主要操作：

- 复制安装命令
- 复制完整安装说明
- 打开来源链接
- 编辑
- 删除

删除操作需要二次确认。

## 4. AI 模型接入

V1 支持模型接入设计，但 GUI 原型只展示流程，不真实调用模型接口。

模型能力：

- 根据用户提供的网址读取或检索资料。
- 在允许联网时调用具备联网能力的 Skill 或工具访问网页。
- 从页面内容中提取 Skill 名称、简介、标签、适用场景、安装步骤、安装命令、来源链接和备注。
- 将结果生成可编辑草稿。

安全规则：

- AI 不直接保存条目，用户确认后才入库。
- AI 不直接执行安装命令。
- AI 不直接删除条目；删除必须经过用户确认。
- 生成结果需要保留来源链接，便于用户核对。

## 5. 编辑界面

编辑界面在右侧详情栏中打开，不跳转页面。

字段包括：

- 名称，必填
- 简短介绍，必填
- 标签，可多选或新建
- 适用场景，多行文本
- 安装步骤，Markdown 文本
- 安装命令，可添加多段命令
- 来源链接
- 兼容平台
- 备注，Markdown 文本

底部操作：

- 保存
- 取消
- 删除

保存后回到详情状态。

## 6. 空状态

### 首次使用

显示提示：

当前还没有 Skill 条目。

提供主操作：

- 新建 Skill
- 导入备份

### 搜索无结果

显示提示：

没有找到匹配的 Skill。

提供操作：

- 清空搜索
- 新建 Skill

### 标签无内容

显示提示：

该标签下暂无 Skill。

提供操作：

- 查看全部 Skills

## 7. 视觉风格

整体风格为桌面效率工具。

设计原则：

- 信息密度适中
- 分栏清晰
- 操作按钮固定且可预测
- 标签和命令区域易扫描
- 避免大面积装饰性视觉元素

建议颜色：

- 背景：浅灰或接近白色
- 主文本：深灰
- 辅助文本：中灰
- 强调色：蓝色或绿色
- 危险操作：红色

## 8. 关键交互

- 应用启动后，右侧默认显示 AI 导入面板。
- 点击 AI 导入按钮后，右侧切换为 AI 导入面板。
- 用户粘贴 Skill 下载网址或资料网址后，点击生成草稿。
- AI 在允许联网时自行查找网页资料，并生成可编辑草稿。
- 用户确认草稿后保存为 Skill 条目。
- 点击 Skill 卡片后，右侧详情立即切换。
- 搜索输入时实时过滤列表。
- 标签点击后过滤列表。
- 点击复制按钮后显示短暂成功提示。
- 编辑未保存时切换条目，需要提示是否放弃修改。
- 删除前必须确认。
- 导入 JSON 时，如存在同名条目，需要选择覆盖、跳过或另存为新条目。

## 9. V1 不包含

- 一键执行安装命令
- 自动扫描本机 Skill 目录
- 在线账号
- 多设备同步
- 远程 Skill 市场
- 权限系统
- 评分、评论、下载量等公开市场功能

## 10. 原型实现建议

首版 GUI 预览可使用单文件 HTML 实现，不依赖数据库和构建工具。原型中使用固定假数据模拟：

- 技能列表
- 标签筛选
- 详情切换
- AI 导入面板
- 搜索过滤
- 编辑状态
- 复制成功提示

后续进入 Electron 开发时，将原型中的静态数据替换为 SQLite 数据访问层即可。
